# Video Studio for macOS

Download the latest `VideoStudio-X.Y.Z.dmg` from [Releases](https://github.com/connorodea/video-studio-releases/releases/latest).

1. Open the DMG and drag **Video Studio** to **Applications**.
2. Open Video Studio and sign in with your API key.

- Requires macOS 13 or later (Apple silicon or Intel).
- The app checks this page for updates once a day (menu: Video Studio > Check for Updates).
- Server: https://studio.medicalrxlab.com

This repository holds release builds only.
